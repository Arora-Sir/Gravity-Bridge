# Security Policy

## Reporting a Vulnerability

We take the security of GravityBridge seriously. If you find a security vulnerability, please do not open a public issue. Instead, please report it privately:

1. Go to the repository's **Security** tab on GitHub: [github.com/Arora-Sir/Gravity-Bridge/security](https://github.com/Arora-Sir/Gravity-Bridge/security).
2. Click on **Report a vulnerability** to open a private draft advisory.
3. Provide details of the vulnerability, including reproduction steps.

We will review the report and coordinate a fix as quickly as possible. Thank you for helping keep GravityBridge secure!
